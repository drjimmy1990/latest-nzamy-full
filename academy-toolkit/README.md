## 1. نظرة عامة
تعتمد أكاديمية نظامي على نموذج التقييم القانوني الذري (Atomic Legal Assessment):
- كل سؤال يرتبط بنظام محدد، ورقم مادة، ومقتطف من النص النظامي.
- تعليل قانوني دقيق وموثق لكل خيار.
- دعم لأربعة أنماط: (اختيار من متعدد MCQ، صح أم خطأ TF، سيناريو قضائي وتطبيقي Scenario، وتوصيل ومطابقة Match).

## 2. هيكل البيانات

```typescript
interface AcademyQuestion {
  id: string;                      // المعرف الفريد للسؤال
  categoryId: AcademyCategoryId;   // معرف القسم (procedural, commercial...)
  categoryNumber: string;          // رقم القسم من "00" إلى "29"
  categoryName: string;            // اسم القسم بالعربية
  lawName: string;                 // اسم النظام
  articleNumber?: string;          // رقم المادة
  type: 'mcq' | 'tf' | 'match' | 'scenario';
  difficulty: 'beginner' | 'intermediate' | 'advanced';
  tags: string[];                  // الوسوم القانونية
  question: string;                // نص السؤال
  options?: string[];              // الخيارات الأربعة
  correctAnswer: number;           // مؤشر الإجابة الصحيحة
  explanation: string;             // التعليل القانوني الشامل
  statutoryCitation: {             // السند النظامي الدقيق
    instrument: string;
    decreeNo?: string;
    article: string;
    textSnippet?: string;
  };
}
```

## 3. الأوامر المتاحة

```bash
# 1. عرض إحصائيات بنك الأسئلة ومستويات الصعوبة وحالة الـ 30 قسماً
npm run academy:status

# 2. فحص وتدقيق سلامة بنك الأسئلة والخيارات والسند النظامي
npm run academy:verify

# 3. زرع وتحديث حزم الأسئلة الثابتة وقاعدة البيانات
npm run academy:seed

# 4. معاينة الزرع بدون تعديل
npm run academy:seed -- --dry-run
```

## 4. جداول قاعدة البيانات
يتم إنشاء الجداول ضمن المخطط `academy` في Supabase عبر ملف الترحيل `supabase/migrations/20260820_academy_schema.sql`:
- `academy.questions`: بنك الأسئلة بكافة حقوله وسنده النظامي.
- `academy.quizzes`: الاختبارات الجاهزة وتصنيفاتها.
- `academy.attempts`: سجل محاولات ونتائج المتدربين ووقت الإجابة.
- `academy.certificates`: الشهادات الرقمية الصادرة برقم تحقق فريد `verify_id`.

## 5. الأقسام القانونية الـ 30 المغطاة
من القسم `00 - الإجرائي والقضائي` إلى القسم `29 - الدولي والمعاهدات`، تشمل:
- التجاري والشركات، الإفلاس، المعاملات المدنية، الأحوال الشخصية، العمل، الملكية الفكرية، الضرائب والزكاة، العقارات، التمويل والسوق المالية، الجرائم المعلوماتية، حماية البيانات (PDPL)، الطاقة، البيئة، الصحة، التحكيم التجاري، وغيرها.
