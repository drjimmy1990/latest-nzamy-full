## ⚡ 2. معمارية التحميل السريع (Performance & Delivery Architecture)

لحماية أداء الموقع ومنع تحميل 33 ميجابايت في المتصفح دفعة واحدة، تم اعتماد استراتيجية **التحميل الهجين (Hybrid Architecture)**:

```
┌──────────────────────────────────────────────────────────────────────────────────┐
│                             استراتيجية التحميل للمنصة                            │
├──────────────────────────────────────────────────────────────────────────────────┤
│ 1. في المتصفح (Frontend):    يقرأ عينة خفيفة وموزونة (0ms Latency) من            │
│                              `src/data/academy/questions.json`                   │
│ 2. في قاعدة البيانات (Cloud):  يتم رفع الـ 16 ألف سؤال إلى جداول سوبابيز          │
│                              `academy.questions` عبر السيدر، وتُسحب بـ API       │
│                              عند طلب اختبار مخصص لنظام محدد.                     │
└──────────────────────────────────────────────────────────────────────────────────┘
```

## 🛠️ 3. أوامر إدارة ومزامنة الأكاديمية (Toolkit CLI Commands)

تم تجهيز الأوامر التالية في `package.json`:

```bash
# 1. عرض حالة بنك الأسئلة في الموقع والأقسام الـ 30:
npm run academy:status

# 2. فحص وتدقيق سلامة الأسئلة ومطابقة الخيارات:
npm run academy:verify

# 3. مزامنة ورفع الأسئلة إلى قاعدة بيانات Supabase:
npm run academy:seed
```
