## 4. Open risks

1. **`_verify.sql` gate for `20260921_04` — CLOSED in the fix pass.** `supabase/migrations/_verify.sql:196-238` now carries a report row plus a `DO` block asserting the constraint `profiles_phone_e164_saudi_mobile` exists **and** is `convalidated`, that `handle_new_user()` contains the `v_phone` clamp, and that zero rows violate `^\+9665[0-9]{8}$`. Proved by `supabase/tests/rls/rehearse-staging-order.sh`: the full plan §3 order ends `rc=0`, and `SKIP=20260921_04 …` ends `rc=3` on exactly this gate (independent review 2026-09-20, section D).
2. **The constraint is a one-way door on a live table.** `VALIDATE` scans every existing row, and any value it cannot salvage is moved into `metadata.invalid_phone_quarantined` and the column nulled. Nothing is deleted and the migration is idempotent in shape, but on production this silently empties `profiles.phone` for every account holding an unsalvageable number — and `hasPhone` then sends those users back through `/onboarding`. The staging apply must report the quarantine count **before** the production apply, and someone has to decide whether those users are contacted.
3. **`handle_new_user()` is re-created, so the newest definition wins.** Any later branch that also `create or replace`s it drops the `v_phone` clamp silently. The migration's own verify block only runs at apply time, so a subsequent overwrite is caught by the standing `_verify.sql` gate (risk 1, now in place: it checks `pg_get_functiondef('public.handle_new_user()')` for `v_phone` on every deploy).
4. **The widened strip set is a deliberate behaviour widening.** `.`, `_`, `/`, NBSP and ZWSP are now separators rather than "letters"; nothing previously accepted became rejected, but a dotted number pasted from a document now succeeds where it used to be refused.
5. **Two phone validators remain by design** — `contactSanitizer.ts`'s `PHONE_RE` (a detector) and `leads/business-assessment/lead.ts` (non-Saudi B2B numbers). Anyone tightening «one phone rule everywhere» should read appendix 03 before touching them.
