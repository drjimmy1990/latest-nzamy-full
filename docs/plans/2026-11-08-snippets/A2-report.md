### Server code
- `src/lib/murshid/murshidData.ts` (pure):
  - Raw and public types.
  - `validateSectorFile`: every card needs an id, a unique id, a matching `sector_no` and an agency name. Steps must exist, each with a numeric `n` ≥ 1 and an action. No string may contain markup. `total_cards_count` must equal the number of cards.
  - `safeHttpsUrl`, `stripUnsafeUrls`, `toPublicCard`, `toPublicSector`, `searchMurshid` and `toPublicChannels`.
  - Search reuses the page's existing grammar (`_circuitsSearch.searchRows`).
- `src/lib/murshid/guideBlocks.ts` (pure):
  - `extractUserGuide` takes the reader slice of the najiz guide.
  - `parseGuideBlocks` produces headings, paragraphs, list items, callouts, tables of string arrays, and code.
  - `parseInline` splits text into bold, italic and code segments.
  - `plainText` returns the text without marks.
  - No HTML is produced anywhere. A `<br>` inside a table cell becomes a line break, and any other `<…>` stays visible text.
- `src/lib/murshid/murshidStore.ts` (server only, uses fs):
  - Reads `src/data/murshid/` through `process.cwd()`. `deploy.sh` runs `next start` from the repo folder, and the build is not `output: "standalone"`.
  - Validates each file and caches the public projection in module memory.
  - Skips and logs any sector file that fails validation.
  - The JSON is read, never imported, so it is not compiled into any chunk.
- Routes. All are GET only, public, and send `Cache-Control: public, max-age=3600, stale-while-revalidate=86400`. Errors send `no-store`.
  - `GET /api/v1/murshid/sectors` returns `{sourceDate, sectors:[{no, code, title, problemCards, agencyCards, total}]}`.
  - `GET /api/v1/murshid/sectors/[n]` returns one sector's cards. `n` must be an integer of 1–2 digits that names a sector; anything else gets 404. `params` is awaited (Next 16).
  - `GET /api/v1/murshid/search?q=` searches agency, problem type and sector title across all sectors. The query is cut to 120 characters. It returns at most 50 matches, plus «هل تقصد؟» suggestions when nothing matches.
  - `GET /api/v1/murshid/channels` returns the 15 national channels.
  - `GET /api/v1/murshid/najiz-guide` returns the guide as blocks.
  - The shared cache helper is `src/app/api/v1/murshid/_cache.ts`.
