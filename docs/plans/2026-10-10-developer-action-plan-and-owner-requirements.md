### ثانياً: الأوامر والخطوات التي يُشغلها المالك على جهازه (Mac Terminal)

وفقاً للدليل الإجرائي المعتمد في ٥ أكتوبر، يُشغل المالك أو أمين المكتبة الأوامر التالية بالترتيب في الطرفية:

```zsh
# 1. تحديث نسخة الكود المحلية
cd ~/Projects/nzamy-website
git checkout owner-edits
git pull
npm ci

# 2. ضبط الجلسة ومسار القبو
export NODE_OPTIONS=--max-old-space-size=8192
VAULT="$HOME/Projects/Raw_Vault"
OUT="$HOME/nzamy-seed/$(date +%Y-%m-%d_%H%M)"

# 3. تطبيق سكريبت الإصلاحات الاثني عشر على القبو
node library-toolkit/owner-fixes-2026-10-05.mjs --vault "$VAULT" --apply

# 4. مطابقة العقد وتحليل الملفات
node scripts/check-schema-manifest-drift.mjs --vault-root "$VAULT"
node library-toolkit/library-parse.mjs --input "$VAULT/01_المكتبة_القانونية" --output "$OUT/parsed"

# 5. تحويل البيانات لصفوف جافة تجريبية (Dry Run)
npx tsx scripts/seed-library.ts --dir "$OUT/parsed" --dry-run --dry-seed-jsonl-dir "$OUT/rows"

# 6. استخراج تقرير المقارنة مع الموقع الحي
node scripts/library-rows-diff.mjs --rows "$OUT/rows"
```
